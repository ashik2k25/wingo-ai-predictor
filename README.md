## ☁️ Deploy to Streamlit Cloud (24/7 Free)

### Step 1: Create GitHub Repository
1. Go to [github.com](https://github.com) → New repository
2. Name: `wingo-ai-predictor` (or any name)
3. Make it **Public**
4. Click **Create repository**

### Step 2: Upload Files
Upload these 3 files to your GitHub repo:
- `wingo_predictor.py`
- `requirements.txt`
- `README.md` (optional)

You can upload via:
- GitHub website (Add file → Upload files)
- Or use Git commands

### Step 3: Deploy on Streamlit Cloud
1. Go to → [https://share.streamlit.io](https://share.streamlit.io)
2. Sign in with your **GitHub** account
3. Click **New app**
4. Select:
   - Repository → `your-username/wingo-ai-predictor`
   - Branch → `main`
   - Main file path → `wingo_predictor.py`
5. Click **Deploy!**

Wait 1-3 minutes. Your app will be live 24/7 🎉
